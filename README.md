# Site Historiando


## O que é o Historiando?

O Historiando é um projeto de Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas, que visa desenvolver um jogo digital lúdico e imersivo para auxiliar no aprendizado de História do Brasil, especificamente os períodos pré-colonial e colonial.
Assim, a fim de complementar a proposta do projeto, foi criado um site que aborda assuntos históricos por meio de cards de conteúdos, mapas mentais e questões retiradas diretamente de vestibulares. 

Se desejar saber mais sobre o Historiando, leia o nosso artigo científico: [clique aqui para baixar](./docs/ARTIGO_Historiando_2026.docx)


## Como rodar (no terminal)
- Primeiro digite o comando : npm i
- Depois digite o comando : npm run dev

## Como fazer um deploy depois de uma atualização (no terminal)
- Primeiro dê : git add .
- Depois: git commit -m "mensagem"
- Construa com : npm run build (certificar de ter criado/ter a pasta 'dist')
- Atualize o repo: git push
- Faça o deploy: npm run deploy
