# Site Historiando

## Como rodar (no terminal)
- Primeiro digite o comando : npm i
- Depois digite o comando : npm run dev

## Como fazer um deploy depois de uma atualização (no terminal)
- Primeiro dê : git add .
- Depois: git commit -m "mensagem"
- Construa com : npm run build (certificar de ter criado/ter a pasta 'dist')
- Atualize o repo: git push
- Faça o deploy: npm run deploy
